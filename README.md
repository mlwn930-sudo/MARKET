# Market Intel

פלטפורמת מחקר לשוק ההון האמריקאי — ניתוח פונדמנטלי של חברות מול חציון
הסקטור, מעקב אחרי גופים מוסדיים, סורק הזדמנויות, וחדשות גאופוליטיות.
כל מקורות הנתונים חינמיים.

---

## איך מריצים את זה

צריך **Node.js** מותקן. אם אין — מורידים מ-[nodejs.org](https://nodejs.org)
ומתקינים (הגרסה שמסומנת LTS).

פותחים טרמינל בתיקייה הזו ומריצים פעם אחת:

```bash
npm install
```

ואז, בכל פעם שרוצים להפעיל:

```bash
npm run dev
```

פותחים בדפדפן: **http://localhost:3000**

לעצירה: `Ctrl + C` בטרמינל.

## רענון נתונים

שום נתון כבד לא נמשך בזמן שגולשים. הכל נבנה מראש לקבצים ונקרא משם —
זה ההבדל בין עמוד שנטען ב-0.1 שניות לעמוד שנטען בשתי דקות.

| פקודה | מה היא מרעננת | כמה זמן | כל כמה זמן |
|---|---|---|---|
| `npm run refresh:news` | פיד החדשות | כדקה | כל 20 דקות |
| `npm run build:fundamentals` | 48 חברות + חציוני סקטור | 3-5 דקות | שבועי |
| `npm run build:institutional` | דוחות 13F של 8 גופים | 2-3 דקות | רבעוני |

אוטומטית זה רץ דרך GitHub Actions — ראה `.github/workflows/README.md`
לתנאים שצריכים להתקיים ולסודות שצריך להגדיר.

## מפתחות

הקובץ `.env.local` מכיל את מפתח ה-API שלך ל-Finnhub.

> **אל תעלה את הקובץ הזה למקום ציבורי.** הוא כבר מוגדר להישאר מחוץ
> לגיט, אבל אם אתה מעביר את התיקייה למישהו אחר — מחק אותו קודם.
> מפתח חדש מוציאים בחינם ב-finnhub.io.

| משתנה | לשם מה | חובה |
|---|---|---|
| `FINNHUB_API_KEY` | מחירים ופרופיל חברה | כן |
| `SEC_USER_AGENT` | SEC דורשת שם ומייל בכל בקשה | כן |
| `FRED_API_KEY` | נתוני מאקרו | עדיין לא בשימוש |
| `DATABASE_URL` | שמירת היסטוריה | עדיין לא בשימוש |

## מקורות הנתונים

| מקור | מה מגיע ממנו | עלות |
|---|---|---|
| SEC EDGAR | דוחות כספיים, XBRL, דוחות 13F | חינם |

`.claude/memory/data_sources.md`. **לקרוא לפני שמוסיפים מקור חדש.**

## שלושה דברים שכדאי לדעת על הנתונים

1. **דוחות SEC מאחרים.** חברה מדווחת רבעון עד 45 יום אחריו. כל מספר
   באתר מוצג עם תאריך הדוח שממנו הוא נלקח, ודוח ישן מ-120 יום מסומן
   בבירור.
2. **13F מאחר יותר.** מוגש עד 45 יום אחרי סוף הרבעון, כולל מניות
   אמריקאיות בלבד, ולא כולל שורט, אג״ח או מזומן — כלומר חלק מהתמונה.
3. **מדד שמוצג כ-"—" לא חושב, ולא הוערך.** אם נתון חסר בדוחות הוא
   נשאר חסר. זה מכוון.
