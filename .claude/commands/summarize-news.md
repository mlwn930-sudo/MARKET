# summarize-news — סיכום וניתוח של כתבות החדשות

> הפעל אחרי רענון החדשות, כדי לכתוב סיכום בעברית וניתוח השפעה לכל כתבה.
> זה מה שהופך רשימת כותרות למשהו שאפשר להשתמש בו.

**קלט:** `$ARGUMENTS` — אופציונלי. שם סקטור (`semis`, `energy`, `defense`,
`finance`, `trade`) כדי לנתח רק אותו. בלי ארגומנט — כל מה שטרם נותח.

---

## למה זה מתכון ולא קוד

הניתוח דורש הבנת שפה, והאלטרנטיבה היא קריאה ל-API בתשלום. המשתמש קבע
אפס עלות חודשית, ולכן העבודה הזו נעשית כאן — במנוי שכבר קיים — והתוצאה
נשמרת לקובץ שהאתר קורא.

## שלבים

1. **קרא את הפיד**
   - `content/news/latest.json` — הכתבות הנוכחיות.
   - `content/news/summaries.json` — מה שכבר נותח, אם הקובץ קיים.
   - **דלג על כתבה שכבר יש לה סיכום.** אין טעם לכתוב אותו פעמיים.

2. **הבא את תוכן הכתבה**
   - משוך את ה-URL וקרא את הטקסט בפועל.
   - **אם הכתבה חסומה מאחורי תשלום או שהמשיכה נכשלה — דלג עליה.**
     אל תסכם מהכותרת. סיכום שנכתב מכותרת בלבד הוא ניחוש שנראה כמו
     ידיעה, וזו בדיוק התקלה שהכי מסוכנת בכלי פיננסי.

3. **כתוב סיכום** — שתי שורות לכל היותר, בעברית.
   - מה קרה, לפי מה שכתוב בכתבה.
   - בלי תארים ובלי דרמה. "אינטל הודיעה על קיצוץ של 15% בכוח האדם"
     ולא "אינטל בצעד דרמטי".

4. **כתוב ניתוח השפעה** — שתיים עד שלוש שורות.
   - **הסבר את המנגנון, לא רק את הקשר.** "מגבלות יצוא על ציוד ליתוגרפיה
     פוגעות ב-ASML כי כ-40% מהכנסותיה מגיעות מאסיה" — ולא "חדשות רעות
     למגזר השבבים".
   - אם ההשפעה לא ברורה, כתוב שהיא לא ברורה. זו תשובה לגיטימית.

5. **דרג משמעות** — `high` / `medium` / `low`
   - `high` — משנה את התמונה לסקטור שלם או לחברה גדולה.
   - `medium` — רלוונטי, אבל לא משנה תזה.
   - `low` — רעש שהגיע לפיד.

6. **תייג חברות** — רשימת טיקרים שהכתבה נוגעת בהם ישירות.
   - רק חברות שמוזכרות בכתבה או שהקשר אליהן ישיר וברור.
   - אל תמתח את הקשר כדי למלא את הרשימה.

## פלט

`content/news/summaries.json`, במבנה:

```json
{
  "writtenAt": "2026-09-22T18:30:00.000Z",
  "summaries": {
    "https://example.com/article": {
      "summary": "...",
      "impact": "...",
      "tickers": ["NVDA", "AMD"],
      "significance": "high",
      "writtenAt": "2026-09-22T18:30:00.000Z"
    }
  }
}
```

המפתח הוא ה-URL של הכתבה. **שמור על ערכים קיימים** — הקובץ נצבר
לאורך זמן, ורענון חדשות לא אמור למחוק ניתוחים שכבר נכתבו.

## כללים

- **אסור להמליץ לקנות או למכור.** לא במפורש ולא ברמז. הניתוח מתאר
  מנגנון השפעה; ההחלטה היא של המשתמש. זה גבול המוצר, לא סגנון.
- **אסור להמציא עובדה שלא מופיעה בכתבה.** אם חסר מידע — לדלג.
- מספרים בכתבה מצוטטים כפי שהם, עם המקור. אל תעגל ואל תשלים.
- עברית, אבל טיקרים ומונחים מקצועיים באנגלית.
- עדכן את `.claude/memory/active_context.md` בסיום.
